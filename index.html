ABOUT TONFISH

PROJECT: TONFISH

🎣 TonFish is a peer-to-peer multiplayer fishing game built on top of Trac Network's Intercom stack.

Players cast their lines in a shared virtual pond. Fish movements, weather conditions, and catch events are broadcast via Intercom P2P sidechannels so all players experience the same world state in real-time without a centralized server.

AI fishing agents roam the pond autonomously, offering tips, competing for rare fish, and maintaining the game economy. They communicate with players and each other over Intercom as first-class network participants.

Caught fish are tokenized as on-chain assets redeemable for TNK — the Trac Network token.
